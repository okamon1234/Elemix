# サバイバーズ：4種ボス・形態変化・決戦マップ拡張版

## 起動と基本操作

ZIPを展開して `RiftSurvivors.exe` を起動します。Unityでは `Assets/RogueSurvivors/Scenes/HomeScene.unity` をPlayしてください。Windows向け開発ビルドです。

ホームでキャラクターと準備時間（30秒～30分）を選び、出撃します。左上の討伐対象ボタンでランダム／4種類のボスを切り替えます。マルチでは部屋主の選択を使います。「ボスの特徴・回復」で変身前後の姿と攻略を確認できます。準備時間が終わるとビルドを保存してロビーへ移動。同じ版を使う最大4人で、同じ部屋名を入力して参加し、部屋主がボス戦を開始します。「ボス戦の練習」はオフライン用です。

移動：WASD／矢印キー／左スティック。攻撃は自動。強化：3択をクリックまたは1・2・3。Escでメニュー。ホームの「武器・属性ガイド」で組み合わせを確認できます。

## キャラクターと選択傾向

| キャラクター | 初期武器 | 特徴 | 出やすい系統 |
|---|---|---|---|
| アーチャー | 風の弓 Lv2 | 移動が速い | 属性 |
| ウォリアー | 回転剣 Lv2 | 取得範囲が広い | 物理 |
| ナイト | 剣・盾 Lv1 | HP150、回復、被ダメージ軽減 | 物理 |
| メイジ | 火の玉 Lv2 | 攻撃力が高い | 属性 |
| ランサー | 槍 Lv2 | 移動・耐久のバランス型 | 物理 |

所持上限は合計6武器、うち属性は最大4武器、各Lv8。属性4＋物理2、属性2＋物理4、物理6などが可能です。強化可能な所持武器があれば3択の1枠はその強化を提示します。残りは重み付き抽選。得意系統の新武器は逆系統の3倍の抽選重みです（カード全体で75%を保証するものではありません）。能力強化も出現し、他系統を選ぶこともできます。

既存セーブの弓は同じIDの「風の弓」として読み込みます。古いナイトの所持品は保存内容を尊重し、新規開始から剣・盾になります。

## 武器：物理9種・属性9種

物理は近接が中心：剣、回転剣、槍、短剣、斧、ハンマー、盾、ナックル、鎌。

属性は遠距離が中心：風の弓、火の玉、雷、氷の杖、水の杖、光の杖、闇の杖、木の杖、土の杖。魔法ごとに直線・地点範囲・連鎖・減速などが異なります。

## 属性反応

同じ敵へ4秒以内に組み合わせとなる属性を当てると反応します。順番はどちらからでも同じです。反応すると付着を消費。同じ敵での反応には0.4秒、ボスには全員共有で0.75秒の再発動待ち時間があります。反応による追加ダメージが別の反応を無限に連鎖させることはありません。

| 組み合わせ | 反応 | 効果 |
|---|---|---|
| 炎＋風 | 大爆発 | 発動攻撃1.8倍＋周囲へ追加ダメージ・炎を拡散 |
| 炎＋雷 | 過負荷 | 発動攻撃2倍 |
| 炎＋氷 | 融解 | 発動攻撃2.4倍 |
| 炎＋水 | 蒸発 | 発動攻撃2.1倍 |
| 水＋雷 | 感電 | 発動攻撃1.6倍＋周囲へ放電 |
| 水＋氷 | 凍結 | 通常敵を1.5秒停止。ボスは停止せず軽い減速 |
| 雷＋氷 | 超電導 | 5秒間、物理ダメージを1.25倍にする |
| 風＋水・氷・雷 | 拡散 | 追加ダメージと属性付着を周囲へ広げる。連鎖反応は起こさない |
| 光＋闇 | 対消滅 | 発動攻撃2.2倍＋周囲へ追加ダメージ |
| 木＋水 | 開花 | 少し遅れて周囲に追加ダメージ |
| 木＋炎 | 燃焼 | 0.6秒間隔で3回の継続ダメージ |
| 木＋雷 | 激化 | 発動攻撃2倍 |
| 土＋炎・水・氷・雷 | 結晶 | 反応を起こしたプレイヤーに5秒間のシールド |

結晶シールドは最大HPの20%までで、重ねて無限に増えません。盾の近接攻撃は小さなシールドを得られます。燃焼・開花は対象が生存中に処理され、死亡すると残りの効果は消えます。

原神の「異なる元素の組み合わせ」という考え方を参考にしつつ、付着時間、倍率、光と闇、炎と風の大爆発などはこのゲーム独自の設計です。原神の全反応や付着量を再現するものではありません。参考：[元素反応の概要](https://genshin-impact.fandom.com/ja/wiki/元素反応)。

## 物理武器の進化

両方の武器がLv4以上になると、表の左側の武器が自動進化します。右側の武器も残ります。進化武器は威力1.5倍になり、射程・攻撃範囲も拡張します。新しい枠は使いません。

| 元の武器 | 組み合わせ | 進化先 |
|---|---|---|
| 剣 | 盾 | 大剣 |
| 回転剣 | 斧 | 回転大斧 |
| 短剣 | ナックル | 双剣 |
| 槍 | 剣 | ハルバード |
| 斧 | ハンマー | 両刃の戦斧 |
| ハンマー | 槍 | ウォーハンマー |
| 盾 | ハンマー | スパイクシールド |
| ナックル | 短剣 | クロー |
| 鎌 | 回転剣 | 大鎌 |

死亡などで素材のどちらかがLv4未満になると進化前へ戻り、条件を再び満たすと再進化します。物理攻撃はボス装甲に対して1.35倍のダメージを与えます。

## 4種類のボスと形態変化

| ボス | 通常形態 | HP50%以降 |
|---|---|---|
| アイアンゴーレム | 突進・連続衝撃波 | 炉心が露出。三連突進・十字粉砕を追加 |
| 大グモ | 毒だまり・扇状の糸 | 太い脚と牙の狩猟形態。蜘蛛の巣・三連針射 |
| ストームドラゴン | 扇状ブレス・翼の輪状弾幕 | 翼が拡大。旋回弾幕・落雷の列 |
| 森の守護者 | 根の追撃・種の輪 | 樹冠と枝が変化。切れ目のある根の迷路・二重弾幕 |

本体HP50%で2.4秒の変身演出に入り、その間は本体無敵です。強い一撃でも変身を飛ばして倒せません。通常・変身後の8枚のオリジナルピクセル画像を収録しています。

後半は攻撃の組み合わせに加え、行動間隔と威力も強化されます。突進の予告は最低0.85秒、連続突進の再予告は0.8秒。設置攻撃は床の縁と色で範囲を表示してから発動します。根の迷路には5単位幅の切れ目があります。

## 部位破壊と攻略順

ボスの右・上・左・下に4つの装甲部位があり、各耐久は本体HPの12%（最低120）。全て壊すまで本体HPは減りません。部位名はボスに応じて腕、翼、脚、枝などに変わります。

攻撃者の位置で狙う部位が決まります。破壊済みの方向から撃ち続けても、残りの装甲や本体にはダメージが通りません。周囲へ回り込むか、マルチで方向を分担してください。

| 破壊方向 | 攻略への効果 |
|---|---|
| 右 | 攻撃威力を20%軽減 |
| 上 | 主な弾幕を2発減らす。旋回弾幕は4方向から3方向へ |
| 左 | 毒・糸・根などの持続時間を30%短縮 |
| 下 | 移動・突進速度を20%低下 |

1部位破壊ごとに行動頻度は6%増加するため、どの攻撃を先に弱めるかを考えられます。攻撃によっては対応部位の効果がありません。例えばゴーレムの突進は下側を壊すと避けやすくなります。

難易度は全参加者のレベル合計と武器・耐久のビルドで決まり、開始時に固定。Lv25が3人なら合計75、4人なら100です。以前より基礎HP・威力・行動頻度を引き上げました。死亡でレベルが下がってもボスは弱体化しません。

## 広い決戦マップと回復

決戦エリアを約32×17から56×36へ拡張しました。各プレイヤーを追うカメラと、右上のミニマップで仲間・ボスの位置を確認できます。中央に広い回避空間を残し、4本の柱を外側へ配置しています。

- **自動回復スキル**：3択で取得可能。毎秒の回復量が0.35増え、上限2。5秒間ダメージを受けなければ回復が始まり、被弾すると中断します。ナイトの初期回復も同じ条件です。死亡による直近強化の取り消し対象になります。
- **応急手当**：ボス戦で全員が使える自動救済。HP45%以下かつ6秒間被弾なしで最大HPの18%を回復。1戦3回まで、再発動まで35秒。死亡・復活しても使用回数は戻りません。
- 左上のHUDに回復量・応急手当の残数と再使用時間を表示します。回復のために一度攻撃範囲から離れる判断が重要です。

## 敵・死亡・保存

敵はスケルトン、ネズミ、重装兵、弓兵、突進兵の5種類。35・55・80秒で後続種が解禁され、時間とともにHP・攻撃力・出現密度が増加します。

60秒以降、一部（18%）が属性持ちになります。同属性ダメージを20%軽減し、HPは通常の1.12倍、経験値は2倍。物理は属性耐性の影響を受けません。属性持ちも全武器で倒せ、属性付着は反応の起点として利用できます。

ソロ・ボス戦とも死亡すると、レベルが最大3下がり、直近3回分の強化を取り消して3秒後に復活します。レベルは最低1。初期武器は保持します。古いセーブに強化履歴がない場合は順番を復元できないため、初期装備を守った代替処理で強化分を減らします。

## 設定・再検証

Tag・Layer・Physics2D・Sorting Layer・Prefab・Scene・UI・基本演出と指定App IDは実プロジェクトへ設定済み。通常のWindowsプレイに追加設定は不要です。日本語フォントはWindowsの游ゴシック等を利用。他OS配布時はフォント確認が必要です。

オンラインは日本リージョン固定。今回の版は通信データが増えたため、新旧版を別の接続バージョンにしています。全員同じ版を使用してください。

1. HomeSceneを再生し、職業の初期武器・属性ガイドを確認。
2. 物理職と遠距離職で3択の傾向を比較。6枠到達後、新武器が出なくなることと、属性4つで新しい属性武器が出なくなることを確認。
3. 反応する武器2つを選び、反応名と効果を確認。
4. 物理武器を表の組み合わせでLv4にし、進化名・範囲を確認。
5. 死亡後の強化取り消しと進化解除を確認。
6. ボスの四方向から攻撃し、全装甲破壊まで本体HPが減らないことを確認。
7. 各ボスを選んで練習し、HP半分でグラフィック・攻撃が変わることを確認。
8. 被弾直後は回復せず、安全な時間を作ると回復すること、応急手当が3回で切れることを確認。
9. 2～4クライアントで同じ部屋に入り、部屋主のボス選択・部位残量・形態・予告・移動・勝利が一致することを確認。

自動検証：Tools > Rogue Survivors > Run Play Mode Smoke Tests。
Windowsビルド：Build Windows Player。
Setupは生成アートやScene・Prefabを更新するため、手動編集後の再実行前にはバックアップしてください。

実行結果と未検証範囲は「検証結果.md」を参照。移行前と今回変更前のバックアップは、実プロジェクトのRogueSurvivorsBackups内に保持しています。

## Unityの設定と主な分担

今回のボス・回復・ミニマップは既存Prefabのコンポーネントから自動構成されます。追加でInspectorへ手動アタッチする必要はありません。MultiBossSceneの四方の壁と、Resources/RogueSurvivors/Art/Bossesの8画像も更新済みです。

ボスの選択・攻撃順はBossCatalog、移動・形態はBossAI、攻撃生成はBossAttackDirector、設置予告と命中はBossHazard、外見はBossAppearance、難易度はBossDifficulty、同期はNetworkEnemySyncへ分割しています。応急手当はBossRecovery、自動回復はPlayerPassiveAbilitiesが担当します。

Editorメニュー「Update Boss Arena and Art」は壁と未生成画像だけを更新します。手描きで差し替えた既存のボスPNGは上書きしません。Windowsビルド時にもこの更新処理を実行します。手動設定が必要なのは、別OS用フォントや新たな研究機器を接続する場合です。脳波機器との接続は今回まだ実装していません。
