# Elemix：初期属性選択・3属性連鎖・破壊順で分岐するボス版

## 起動と基本操作

ZIPを展開して `RiftSurvivors.exe` を起動します。Unityでは `Assets/RogueSurvivors/Scenes/HomeScene.unity` をPlayしてください。Windows向け開発ビルドです。

ホームでキャラクターと準備時間（30秒～30分）を選び、出撃します。左上の討伐対象ボタンでランダム／4種類のボスを切り替えます。マルチでは部屋主の選択を使います。「ボスの特徴・回復」で変身前後の姿と攻略を確認できます。準備時間が終わるとビルドを保存してロビーへ移動。同じ版を使う最大4人で、同じ部屋名を入力して参加し、部屋主がボス戦を開始します。「ボス戦の練習」はオフライン用です。

移動：WASD／矢印キー／左スティック。攻撃は自動。強化：3択をクリックまたは1・2・3。Escでメニュー。ホームの「武器・属性ガイド」で組み合わせを確認できます。

## キャラクターと選択傾向

| キャラクター | 初期武器 | 特徴 | 出やすい系統 |
|---|---|---|---|
| アーチャー | 風の弓 Lv2 | 移動が速い | 属性 |
| ウォリアー | 回転剣 Lv2 | 取得範囲が広い | 物理 |
| ナイト | 剣・盾 Lv1 | HP150、回復、被ダメージ軽減 | 物理 |
| メイジ | 9属性から選んだ武器 Lv2 | 攻撃力が高い | 属性 |
| ランサー | 槍 Lv2 | 移動・耐久のバランス型 | 物理 |

所持上限は合計6武器、うち属性は最大4武器、各Lv8。属性4＋物理2、属性2＋物理4、物理6などが可能です。強化可能な所持武器があれば3択の1枠はその強化を提示します。残りは重み付き抽選。得意系統の新武器は逆系統の3倍の抽選重みです（カード全体で75%を保証するものではありません）。能力強化も出現し、他系統を選ぶこともできます。

メイジを選ぶと「初期属性」ボタンが表示されます。炎・水・氷・雷・風・木・土・光・闇から選びます。選択は次回の出撃にも保存されます。初期装備はビルドにも記録し、死亡時の取り消しやオンライン移動で保持します。メニューで選び直しても保存済みのビルドは変わりません。旧セーブのメイジは従来の炎から開始した扱いです。

既存セーブの弓は同じIDの「風の弓」として読み込みます。古いナイトの所持品は保存内容を尊重し、新規開始から剣・盾になります。

## 武器：物理12種・属性9種

物理12種：剣、回転剣、槍、短剣、斧、ハンマー、盾、ナックル、鎌、鞭、ボウガン、ブーメラン。短剣・斧・鎌も投げて攻撃します。全てに合体先があります。

属性は遠距離が中心：風の弓、炎の玉、雷の指輪、氷の槍、水のオーブ、光の槍、闇のオーブ、木の種、土のハンマー。魔法ごとに直線・地点範囲・連鎖・減速などが異なります。

## 育成と属性武器の特徴

- 進化相手の抽選重みは、対応する所持武器がLv1〜3なら3倍、Lv4以上なら4倍。短剣を取るとナックルが出やすくなります。職業の得意系統の重みと掛け合わせます。確定出現ではありません。
- 近接物理で4m以内の敵を倒すと経験値25%増加。その経験値は自動で吸い寄せます。端数を次の撃破へ持ち越すため、通常の経験値2の敵を4体倒すと合計10になります。
- 物理も投げナイフ、投げ斧、往復する鎌などで遠くへ攻撃できます。接近時は経験値追加と小さな数値シールドでリスクを補います。
- 氷：扇状の氷片と氷柱。水：2〜5回の連続波。木：左右に広がる連続の棘。土：岩柱の突き上げ。Lv3・5・8で範囲や数が増え、氷・土・光はLv5から2回攻撃。
- 氷・水・光・闇・木・土の属性武器は毎レベル基礎威力が5増え、発動間隔が0.12秒短縮。3択に現在→次レベルと威力を表示します。
- 光＋闇を両方Lv4にすると「光の大槍」「闇の重力球」へ進化。両方の威力1.5倍、光の貫通演出と闇の範囲・吸引を強化。反応「対消滅」は2.8倍。

## 属性反応

同じ敵へ4秒以内に組み合わせとなる属性を当てると反応します。順番はどちらからでも同じです。拡散では元の敵に元素を残し、それ以外の反応では付着を消費。同じ敵での反応には0.4秒、ボスには全員共有で0.75秒の再発動待ち時間があります。反応による追加ダメージが別の反応を無限に連鎖させることはありません。

| 組み合わせ | 反応 | 効果 |
|---|---|---|
| 炎＋風 | 拡散 | 発動攻撃1.3倍、元の敵に炎が残り、周囲へ付着と追加ダメージ |
| 炎＋雷 | 過負荷 | 発動攻撃2倍 |
| 炎＋氷 | 融解 | 発動攻撃2.4倍 |
| 炎＋水 | 蒸発 | 発動攻撃2.1倍 |
| 水＋雷 | 感電 | 発動攻撃1.6倍＋周囲へ放電 |
| 水＋氷 | 凍結 | 通常敵を1.5秒停止。ボスは停止せず軽い減速 |
| 雷＋氷 | 超電導 | 5秒間、物理ダメージを1.25倍にする |
| 風＋水・氷・雷 | 拡散 | 発動攻撃1.3倍。元の敵にも属性を残す。周囲の追加ダメージで反応は再帰しない |
| 光＋闇 | 対消滅 | 発動攻撃2.8倍＋周囲へ追加ダメージ |
| 木＋水 | 開花 | 対象に種が3秒残り、時間切れで半径2.8mへ追加ダメージ |
| 開花した敵＋雷 | 超開花 | 追尾する種弾。0.32秒後に単体へ追加ダメージ |
| 開花した敵＋炎 | 烈開花 | 0.28秒後に半径3.6mへ追加ダメージ |
| 木＋炎 | 燃焼 | 0.6秒間隔で3回の継続ダメージ |
| 木＋雷 | 激化 | 発動攻撃2倍 |
| 土＋炎・水・氷・雷 | 結晶 | 一撃を無効にする結晶アイテムを1個生成。拾うとバリア獲得 |

開花の種は敵1体につき、チーム全体で1個まで。作り直して時間を延ばしたり、同じ種を2回起爆したりできません。種の付いた敵へ雷・炎を当てる操作で派生します。地面の種へ狙いを合わせる方式ではありません。派生ダメージは「種を作った攻撃と起爆攻撃の平均威力」に超開花2.2、烈開花1.55を掛けます。超開花は単体、烈開花は群れ向け。反応ダメージから新しい種は生まれず、味方への自傷もありません。

結晶は地面に1個、保持も1個まで。アイテムは18秒で消え、取得後のバリアは次の一撃または死亡まで持続します。反応を起こした人だけが拾えます。金色の六角形とHUD「結晶◆1」で確認でき、被弾で砕けます。物理攻撃の小さな数値シールドとは別の効果です。燃焼・開花は対象が生存中に処理され、死亡すると残りの効果は消えます。

原神の「異なる元素の組み合わせ」という考え方を参考にしつつ、付着時間、倍率、光と闇などはこのゲーム独自の設計です。原神の全反応や付着量を再現するものではありません。参考：[Game8の元素反応解説](https://game8.jp/genshin/350271)。

## 物理武器の合体：10種類

素材2本がそれぞれLv4になると自動で1本へ合体し、武器枠が1つ空きます。素材2本の通常攻撃は停止し、新しい武器が専用の攻撃を行います。合体は最大5本。最後の1枠に通常武器を持つ「合体5＋通常1」も可能です。同じ素材を複数の合体で使うことはできません。

| 素材1 | 素材2 | 合体武器 | 攻撃 |
|---|---|---|---|
| 剣 | 盾 | 大剣 | 巨大な二連なぎ払い |
| 回転剣 | 斧 | 回転大斧 | 大斧が外へ広がって戻る |
| 短剣 | ナックル | 投刃グローブ | 貫通ナイフの高速連射 |
| 槍 | 剣 | ハルバード | なぎ払いと貫通突き |
| 斧 | ハンマー | 投擲戦斧 | 大きな斧を二方向へ投げる |
| ハンマー | 槍 | 鎖鉄球 | 鎖付き鉄球を振り回す |
| 盾 | ハンマー | スパイクシールド | 敵の間を跳ね返る盾 |
| 鎌 | 回転剣 | 円盤鎌 | 扇状に飛んで戻る刃の円盤 |
| 鞭 | 鎌 | 鎖鎌 | 長い鎖のなぎ払いと往復する鎌 |
| ボウガン | ブーメラン | 連射ボウガン | 大型の金属矢を扇状に連射 |

素材がLv4＋Lv4なら合体Lv1。Lv4を超えた分も引き継ぎ、素材の合計Lv−7が合体Lvです（上限Lv8）。以後は合体武器のカード1回につきLv1上がります。素材への投資は内部で保存されます。条件成立順を保存し、複数が同時成立した場合だけ表の上から判定します。HUDでは合体武器に◆を表示します。

例：大剣・回転大斧・投刃グローブ・鎖鉄球・鎖鎌＋ボウガン。11種類の素材から6枠になり、5本の合体が共存します。

死亡時は直近3回の強化と合体前の構成を巻き戻します。合体後に取った新武器も取得順に取り消すため、合体解除で枠が溢れません。新形式のセーブは素材レベルと合体の対応を保持し、旧形式も読み込めます。旧形式に履歴がない場合だけ代替の減少処理を使います。

物理は装甲へ1.35倍、4m以内の物理撃破は経験値25%増加。属性は遠距離の範囲・連鎖・凍結・反応が強みです。風の弓は同じ一斉射撃の2発目以降が同じボスへ当たる場合15%の威力になり、大きなボスへ全弾が重なる偏りを抑えています。通常敵の威力は変わりません。

投げナイフ・投げ斧・鞭の攻撃形式は [Vampire Survivors](https://poncle.games/vampire-survivors) を参考にし、合体の組み合わせ・名称・画像・処理は本作で作成しています。

## 4種類のボスと形態変化

| ボス | 第1形態 | 第2形態：最初の部位破壊 | 第3形態：本体HP50% |
|---|---|---|---|
| アイアンゴーレム | 突進・衝撃波 | ハンマー大なぎ払い・三連突進 | 広がる衝撃環と連続するなぎ払い |
| 大グモ | 毒だまり・糸 | 出口のある縮む巣・連続毒針 | 毒針が増え、巣と網の攻撃が頻発 |
| ストームドラゴン | ブレス・翼の弾幕 | 旋回ブレス・連続落雷 | 落雷地点が増え、ブレスの旋回範囲拡大 |
| 森の守護者 | 根の追撃・種 | 回転する根・根の迷路 | 中央が安全な収穫の輪・根の旋回範囲拡大 |

変身は各2.4秒で、その間は部位と本体が無敵。HP50%の変身を大きな一撃で飛ばすことはできません。4ボス×3形態の12枚のオリジナルピクセル画像を収録しています。

後半は攻撃の組み合わせに加え、行動間隔と威力も強化されます。突進の予告は最低0.85秒、連続突進の再予告は0.8秒。設置攻撃は床の縁と色で範囲を表示してから発動します。根の迷路には5単位幅の切れ目があります。

## 部位破壊と攻略順

ボスの右・上・左・下に4つの装甲部位があり、各耐久は本体HPの12%（最低120）。全て壊すまで本体HPは減りません。部位名はボスに応じて腕、翼、脚、枝などに変わります。

攻撃者の位置で狙う部位が決まります。破壊済みの方向から撃ち続けても、残りの装甲や本体にはダメージが通りません。周囲へ回り込むか、マルチで方向を分担してください。

どの方向でも、壊すたびに怒りが上がります。破壊数に応じて攻撃力は `1 + 0.075 × 破壊数`、行動頻度は `1 + 0.08 × 破壊数`。第2形態ではさらに威力1.08倍・頻度1.12倍、第3形態では威力1.22倍・頻度1.3倍。破壊でボスを弱める旧仕様は廃止しました。全装甲を壊すには、強くなるボスの周りを回り込む必要があります。

難易度は全参加者のレベル合計と武器・耐久のビルドで決まり、開始時に固定。Lv25が3人なら合計75、4人なら100です。以前より基礎HP・威力・行動頻度を引き上げました。死亡でレベルが下がってもボスは弱体化しません。

## 広い決戦マップと回復

決戦エリアを約32×17から56×36へ拡張しました。各プレイヤーを追うカメラと、右上のミニマップで仲間・ボスの位置を確認できます。中央に広い回避空間を残し、4本の柱を外側へ配置しています。

- **自動回復スキル**：3択で取得可能。毎秒の回復量が0.35増え、上限2。5秒間ダメージを受けなければ回復が始まり、被弾すると中断します。ナイトの初期回復も同じ条件です。死亡による直近強化の取り消し対象になります。
- **応急手当**：ボス戦で全員が使える自動救済。HP45%以下かつ6秒間被弾なしで最大HPの18%を回復。1戦3回まで、再発動まで35秒。死亡・復活しても使用回数は戻りません。
- 左上のHUDに回復量・応急手当の残数と再使用時間を表示します。回復のために一度攻撃範囲から離れる判断が重要です。

## 敵・死亡・保存

敵はスケルトン、ネズミ、重装兵、弓兵、突進兵の5種類。35・55・80秒で後続種が解禁され、時間とともにHP・攻撃力・出現密度が増加します。

60秒以降、一部（18%）が属性持ちになります。同属性ダメージを20%軽減し、HPは通常の1.12倍、経験値は2倍。物理は属性耐性の影響を受けません。属性持ちも全武器で倒せ、属性付着は反応の起点として利用できます。

ソロ・ボス戦とも死亡すると、レベルが最大3下がり、直近3回分の強化を取り消して3秒後に復活します。レベルは最低1。初期武器は保持します。古いセーブに強化履歴がない場合は順番を復元できないため、初期装備を守った代替処理で強化分を減らします。

## 設定・再検証

Tag・Layer・Physics2D・Sorting Layer・Prefab・Scene・UI・基本演出と指定App IDは実プロジェクトへ設定済み。通常のWindowsプレイに追加設定は不要です。日本語フォントはWindowsの游ゴシック等を利用。他OS配布時はフォント確認が必要です。

オンラインは日本リージョン固定。今回の版は通信データが増えたため、新旧版を別の接続バージョンにしています。全員同じ版を使用してください。

1. HomeSceneを再生し、職業の初期武器・属性ガイドを確認。
2. 物理職と遠距離職で3択の傾向を比較。6枠到達後、新武器が出なくなることと、属性4つで新しい属性武器が出なくなることを確認。
3. 反応する武器2つを選び、反応名と効果を確認。
4. 物理武器を表の組み合わせでLv4にし、進化名・範囲を確認。
5. 死亡後の強化取り消しと進化解除を確認。
6. ボスの四方向から攻撃し、全装甲破壊まで本体HPが減らないことを確認。
7. 各ボスで最初の部位破壊とHP半分の2回、グラフィック・攻撃が変わることを確認。
8. 被弾直後は回復せず、安全な時間を作ると回復すること、応急手当が3回で切れることを確認。
9. 2～4クライアントで同じ部屋に入り、部屋主のボス選択・部位残量・形態・予告・移動・勝利が一致することを確認。

自動検証：Tools > Rogue Survivors > Run Play Mode Smoke Tests。
Windowsビルド：Build Windows Player。
Setupは生成アートやScene・Prefabを更新するため、手動編集後の再実行前にはバックアップしてください。

実行結果と未検証範囲はリポジトリの `docs/物理合体とバランス検証.md` を参照。移行前と今回変更前のバックアップは、実プロジェクトのRogueSurvivorsBackups内に保持しています。

## Unityの設定と主な分担

今回のボス・回復・ミニマップは既存Prefabのコンポーネントから自動構成されます。追加でInspectorへ手動アタッチする必要はありません。MultiBossSceneの四方の壁と、Resources/RogueSurvivors/Art/Bossesの12画像も更新済みです。

ボスの選択・攻撃順はBossCatalog、移動・形態はBossAI、攻撃生成はBossAttackDirector、設置予告と命中はBossHazard、外見はBossAppearance、難易度はBossDifficulty、同期はNetworkEnemySyncへ分割しています。応急手当はBossRecovery、自動回復はPlayerPassiveAbilitiesが担当します。

Editorメニュー「Update Boss Arena and Art」は壁と未生成画像だけを更新します。手描きで差し替えた既存のボスPNGは上書きしません。Windowsビルド時にもこの更新処理を実行します。手動設定が必要なのは、別OS用フォントや新たな研究機器を接続する場合です。脳波機器との接続は今回まだ実装していません。

## 攻撃の見た目

氷・水・木・土・光・闇は細い線だけの共通演出から、属性別の形と着弾演出へ変更しました。氷は結晶と雪の紋様、水は波と水しぶき、木は突き上げる芽と葉、土は岩柱と破片、光は翼状の光片を伴う槍、闇は星屑を吸い込む渦です。Lv3・5・8の段階で数・範囲・演出の大きさが増えます。

近接武器は武器本体の振り抜き・突きに、斬撃軌跡と命中の火花を追加。ハンマーと盾には衝撃環、投げた鎌には回転軌跡があります。ボスは変身時の放出、後半形態の残光、固有攻撃の岩・葉・光片を追加しました。攻撃の予告と安全な切れ目を隠さない範囲に装飾を限定しています。
