# 雑魚と攻撃のグラフィック

2026-09-26。雑魚と攻撃を、既存の描き込みのあるキャラクター・ボスに合わせて更新しました。

## 雑魚5種類

| 種類 | 見た目 |
|---|---|
| 骸骨兵 | 割れた兜、露出した骨、欠けた剣 |
| 大ネズミ | 茶色い毛並み、長い尾、低い四足の姿勢 |
| 重装兵 | 大きな盾、厚い鉄鎧、メイス |
| 弓兵 | 赤茶色のフード、弓、矢筒 |
| 突進獣 | 大きな牙、逆立つ毛、前傾した体 |

各種類に待機・左足・右足の3フレームを用意。移動方向への反転、小さな上下動、突進中の姿勢を追加しました。画像のみを変更し、敵のHP・接触ダメージ・移動速度・コライダー寸法は維持しています。

## 攻撃の描画

- 炎の渦、水の波、氷柱、雷撃、風の渦、木の根、岩、光の衝撃、闇の渦、銀色の斬撃、矢、敵の弾を新しく描画。
- 属性攻撃の着弾・反応、炎弾の爆発、雷の命中、物理武器の斬撃に新素材を使用。
- 敵弾と風弾に短い軌跡を追加。敵弾は味方の攻撃演出より前面に描画。
- 弓兵は射撃の0.35秒前から方向を予告し、その方向へ発射します。発射間隔・威力・弾速は維持。初弾に予告時間が入り、照準が途中で追尾しないため、見て避けやすくなります。
- 突進獣は既存の0.7秒の構え中、進行方向と幅を予告。突進速度・時間は維持。障害物の回避で実際の進路が曲がることはあります。
- 着弾素材は短時間で消え、同時表示は最大72個。敵の危険範囲を覆わないように表示順と透明度を設定しています。これは追加した描画の上限で、ゲーム全体のエフェクト数を制限するものではありません。

## 素材・設定

素材は `Assets/RogueSurvivors/Resources/RogueSurvivors/Art/Battle/` の6画像です。透過を保持して取り込み、実行時に切り分けます。元の画像とPrefabは残し、既存のEnemyAIから表示用クラスを追加するため、Inspectorでの手動設定は不要です。

[素材の生成プロンプトと制作方法](雑魚と攻撃素材の制作記録.md)、[各スクリプトの役割](スクリプト役割一覧.md)も参照してください。

## 手動確認

1. HomeSceneからソロを開始し、骸骨とネズミの歩行・向き・被弾点滅を確認する。
2. 経過35秒以降の重装兵、55秒以降の弓兵、80秒以降の突進獣を確認する。弓兵は予告後に矢を放ち、突進獣は進行範囲を予告する。
3. メイジで氷・水・木・土などを取得し、Lv1とLv8の着弾を比較する。
4. 物理武器や合体武器を使い、敵弾・ボスの危険範囲が味方演出の前面に見えることを確認する。
5. 後半の混戦で、敵の種類を判別できること、表示負荷と操作感を確認する。
