# 雑魚の攻撃予告を非表示

- 弓兵・突進獣のオレンジ色の予告線と矢印を削除しました。
- 突進前の「!」と点滅も削除しました。
- 攻撃の準備時間・照準・ダメージ・攻撃頻度は変更していません。敵弾・被弾時の表示・ボスの予告は維持しています。
- UnityのWindowsビルド成功。エラー0・警告0。
- 最終Windows版で雑魚の攻撃準備・射撃・混戦を描画し、予告線が出ないことを目視確認しました。
- 表示のみの変更のため、今回は既存の全PlayModeテスト・ネットワークテストの再実行はしていません。

追加のInspector設定は不要です。HomeSceneから出撃し、弓兵・突進獣が出現した際に予告線がなく、攻撃自体は続くことを確認できます。
