# 戦闘・演出改良と検証（2026-09-24）

## 変更内容

- 物理武器9種・属性武器9種を維持。進化相手がある物理武器の抽選重みを3〜4倍にし、職業の傾向と併用。
- 近接武器の威力・頻度を調整。回転剣の内側の当たり抜け、槍の射程外への空振りを修正。近距離の物理撃破は経験値25%追加・吸い寄せ、命中時に短時間の小さな防御を付与。
- 杖の段階成長をLv3・5・8に設定。水の連続波、木の連続突き上げ、氷の広域結晶、土の岩柱、光の貫通槍、闇の引き寄せを区別。強化カードに威力と次の段階の恩恵を記載。
- 炎＋風の大爆発を拡散へ統一。炎・水・雷・氷を拡散し、元の敵にもその属性を残す。単体ボスでも次の反応へ接続可能。
- 光＋闇の反応を強化。両方Lv4で光の大槍・重力の杖へ同時進化。死亡で条件を失うと解除。
- 結晶は地面に一つ出現する取得アイテムへ変更。取得後は金色の六角バリアとHUDで表示し、被弾一回を無効化して消滅。
- 4ボス×3形態。最初の部位破壊で第2形態、本体HP50%で第3形態。各部位破壊で威力と行動頻度が上がる。
- 固有攻撃8種を追加し全24種。広がる衝撃環、出口のある縮む巣、旋回ブレス、連続落雷、回転根、中央が安全な収穫の輪など、回避方法を変える。
- 杖の結晶・葉・岩・水しぶき・光片、物理の振り抜き・残像・火花、反応演出、ボス変身と大技の装飾を追加。演出の乱数で戦闘用乱数を消費しない実装。
- Fusionの形態・固有攻撃・杖・反応・バリア同期を更新。新旧クライアントは別接続バージョン。
- GitHub公開、個別Photon設定の除外、日本語README、全107クラスの役割を記録。

## 実プレイによる物理と遠距離の比較

UnityのSoloSceneで移動、敵スポーン、攻撃、経験値取得、3択、死亡・復活を動かした自動プレイです。数式だけのDPS比較ではありません。各職業120ゲーム秒×2シード。移動は同じ方針で、射程に応じた接近距離だけ変更し、3択は同分類の取得済み武器を優先しました。

今回の標本では物理職の成長が遠距離を下回らず、平均到達レベルは約9〜15%上でした。ただし各職2回のみで、選択候補・フレーム進行・死亡ペナルティによる変動があります。同レベルを保証する結果でも、人間の操作感を評価した結果でもありません。長時間・熟練度別の調整は今後も必要です。

## 手動で再確認する手順

1. HomeSceneで職業・準備時間・討伐対象を選択しソロを開始。
2. 短剣などを取得し、対応する進化相手が3択に出やすくなることを複数回確認。
3. 杖をLv1・3・5・8へ育て、数・範囲・着弾演出と強化カードの説明を比較。
4. 炎と風で拡散し、単体敵でも炎付着が残ることを確認。水＋炎・氷・雷、雷＋氷も確認。
5. 光と闇をLv4にして同時進化。死亡時の強化取り消しで条件を失うと解除されることを確認。
6. 結晶を拾い、金色の六角表示が出て一度だけ被弾を無効化することを確認。
7. ボスの最初の部位破壊で第2形態、全装甲破壊後の本体HP50%で第3形態に移ることを確認。
8. 4ボスの旋回・環・巣・根をそれぞれ避け、安全な切れ目と実際の判定が一致することを確認。
9. 同じ最新版の2〜4クライアントで入室し、部位・形態・予告・杖演出・バリア・勝利を比較。

## Unity Editorの設定

既存の実プロジェクトではSDK、個別App ID、Scene、Prefab、タグ、レイヤー、衝突行列は設定済みです。今回追加した演出はコードから生成するため、Inspectorへの手動アタッチは不要です。

GitHubから新しく取得する場合はREADMEに従いFusion 2.0.5をインポートし、自分のApp IDを設定してください。SDKと個別App IDは公開していません。他OSの日本語フォント、4人・別回線・長時間・ホスト交代、研究機器との連携は今回の検証範囲外です。
