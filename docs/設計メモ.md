# Elemixの差別化と今回の設計

「個人で作ったビルドを、仲間とのボス解体へ持ち込む」を中心にしています。属性武器を増やすだけでなく、持ち寄った構成で何を分担するかが変わるゲームを目指します。

## 今回のプレイへの反映

- **部位破壊が進捗と危険の両方になる。** 最初の破壊で第2形態へ移り、その後も破壊数に応じて威力と頻度が上がります。全装甲破壊後は本体を削り、半分で第3形態。四方向を分担する価値が残ります。
- **近接と遠距離で得意な仕事が違う。** 物理は全12種類に合体先を持ち、素材2本を1本へまとめて枠を空けます。装甲に1.35倍、近接撃破の経験値25%増加・吸引。属性は離れた場所から付着・反応・凍結を担当できます。物理にも投擲武器があります。ソロでも両方を混ぜられます。
- **拡散で次の反応を準備する。** 元の敵にも炎・水・氷・雷を残すため、ボス1体でも次の味方の攻撃を活かせます。反応の待ち時間はボス全員共有0.75秒として、人数分の無制限連鎖を防いでいます。
- **ボスごとに移動の正解が変わる。** ゴーレムは環の切れ目、クモは縮む巣の出口、ドラゴンは旋回ブレスの背後、守護者は収穫の輪の内側。見た目だけを変えた同じ弾幕にならないよう、線・輪・回転・遅延地点を使い分けています。
- **育成の節目を見せる。** 属性攻撃はLv3・5・8で変化。光と闇にも同時進化を用意しました。物理の進化相手は抽選に重みを付け、組み合わせを完成させる過程を作っています。

## 参考にした観点

[Hadesの公式更新記録](https://www.supergiantgames.com/blog/hades-updates/)で扱われている武器の形態、攻撃速度・威力・視覚表示の調整を参考に、今回も数値だけでなく攻撃の形と育成段階を一緒に変更しました。

[Monster Hunter公式のFocus Mode紹介](https://www.youtube.com/watch?v=_v3lnXyNFhI)は、狙う場所を明確にして攻撃機会を作る観点の参考です。本作の「部位を壊すほど怒る」というルールは、ユーザーの希望に合わせた独自の仕様です。

原神の元素の組み合わせはユーザー指定の着想です。本作では属性数制限、共有待ち時間、光・闇の進化、1回防御の拾得品に合わせて再設計しており、付着量や全ての反応を原作どおりには再現していません。画像・コード・音声の流用はしていません。

## 今後、差別化をさらに深めるなら

次の優先候補は、ボス戦前の「仲間の属性・進化と不足役割の表示」、部位を狙う方向のピン、ボスごとの協力目標です。現状は部位の方向ごとの破壊効果を共通化しているため、将来はボスごとに「どこを壊すと何が激しくなるか」を作る余地があります。

脳波連携は未実装です。導入する場合は、まず攻撃速度の変更範囲を小さく制限し、欠損時は通常速度へ戻すこと、全員の同期による減速は短時間かつ再発動待ち時間を持つこと、同じ効果を研究用の模擬入力でも再現できることを分けて設計すると、通常のゲームバランスと研究条件を比較しやすくなります。
