# 属性反応と物理の火力・手応え

## 反応の成立と火力

反応が分かりにくかった原因として、ボスで0.75秒続く共通の待ち時間、連続攻撃の小さなヒットをそのまま反応の基準にしていたこと、種の付いた敵を倒すと開花が消えることがありました。過負荷には周囲への追加ダメージもありませんでした。

- 付着時間を4秒から6秒へ延長。
- 通常反応の待ち時間を雑魚0.4→0.18秒、ボス0.75→0.3秒に短縮。待ち時間中の同じ反応を無制限には発生させません。
- 反応に使う基準威力Pは、命中威力と「(12＋プレイヤーレベル×1.1)×攻撃倍率」の高い方。レベル部分は50で上限。連続攻撃の弱いヒットにも反応の手応えを持たせます。
- 表の一撃は「通常の命中威力＋P×(倍率−1)」。Pが通常の命中威力と等しければ表記倍率そのものになります。

| 反応 | 強化後 |
|---|---|
| 過負荷 | 一撃3.2倍相当、周囲3.5mにP×1.8の爆発 |
| 融解 | 一撃3.6倍相当 |
| 蒸発 | 一撃3.2倍相当 |
| 感電 | 一撃2.2倍相当、周囲にP×1.1 |
| 対消滅 | 一撃3.6倍相当、周囲にP×1.65 |
| 激化 | 一撃3倍相当 |
| 凍結 | 一撃1.5倍相当、雑魚の停止2.4秒。凍結中の物理追撃に氷砕きの追加ダメージ（同じ敵で0.8秒間隔） |
| 燃焼 | 最初の一撃1.2倍相当、0.5秒ごとにP×0.65を6回。再付着で次のダメージ時刻が先延ばしにならない |
| 開花 | 3秒後にP×2.1の範囲爆発。敵を倒した場合も次フレームに爆発 |
| 超開花 | 種と起爆攻撃の平均威力×4.5の追撃。対象が倒れたら6m以内の敵を探す |
| 烈開花 | 種と起爆攻撃の平均威力×3.2、4.2mの範囲爆発 |
| 超電導 | 一撃1.5倍相当、5秒間の物理補正を1.25→1.4倍に強化 |

凍結でボスの行動を完全停止させることはなく、減速と氷砕きによる追撃を利用できます。開花の種は引き続き敵1体につき1個です。追加ダメージから新たな反応・種を生成しないため、爆発が無限に増殖することはありません。

## 拡散・結晶は支援

拡散は属性を周りへ付着させる支援です。元の属性・残り時間を消費せず、通常反応の時計にも触れず、追加ダメージは発生しません。結晶は拾うと一撃を無効にするバリア。バリア保持中は反応を起こさず、攻撃力の増幅もありません。

## 反応撃破の経験値

反応で倒した敵が9m以内なら、経験値をすぐに引き寄せます。経験値量は増やしません。物理近接の既存の経験値ボーナスは維持します。群れを倒した後で危険な場所へ回収に戻る必要を減らし、次の強化へつながる手応えを付けます。

## 物理と表示

通常の物理武器の命中威力を35%増加。物理合体はさらに30%強化（合計で旧版比75.5%増）。ボス装甲に対する既存の1.35倍は維持しています。オンラインで大きな合体攻撃が240で頭打ちになっていたため、検証付きの受信上限を800×攻撃倍率へ修正しました。命中時の追加火力をそのままボスHPへ再加算して、強化の効果を相殺することはしません。

反応の数字は大きく色付きで表示し、短い着弾音と鋭い破片・水しぶき・氷片を追加。反応名と音は短時間の連発を抑え、ボスの予告より背面へ描画します。撃破時の紫色の四角い粒も短い破片へ変更し、混戦での表示数を抑えています。雑魚の攻撃予告は非表示のままです。

## 確認方法

1. メイジで水を選び、炎を取って蒸発、氷を取って凍結を確認する。
2. 炎＋雷で周囲の敵も巻き込む過負荷、木＋炎で継続して削る燃焼を確認する。
3. 水＋木の種を付けた敵を倒し、残った周囲の敵へ爆発することを確認。雷・炎による3属性の追撃も比較する。
4. 物理ビルドの雑魚処理と装甲破壊を確認。氷＋水を併用すると物理で氷砕きが起きる。
5. マルチは全員この版へ更新して接続し、大きな反応数字・種・部位の残量を確認する。

追加のInspector設定は不要です。既存セーブのレベルや所持武器を変更しません。

参考：[ユーザー指定の原神・元素反応解説](https://game8.jp/genshin/350271)。増幅・範囲爆発・継続ダメージ・支援という役割分担を参考にし、このゲームの攻撃頻度と装甲戦に合わせて数値を調整しています。原神の計算式の再現ではありません。

## ボス火力の実測

同じ48強化分の装備で、静止した本体へ8秒間攻撃した平均ダメージ／秒です。装甲の破壊や回避時間はこの表に含みません。

| ビルド | 変更前 | 最終版 | 増加 |
|---|---:|---:|---:|
| 物理合体 | 921 | 1607 | 約74% |
| 蒸発・融解・凍結 | 1247 | 1564 | 約25% |
| 光・闇 | 1094 | 1467 | 約34% |
| 超開花 | 1308 | 1716 | 約31% |
| 烈開花 | 1304 | 1699 | 約30% |

16・32・48強化分の装甲／本体測定と、4種類のボスを使った自動移動戦闘も実施しました。初回の調整後測定で物理合体の中盤以降が低かったため追加強化し、物理の7条件を再測定しています。遭遇時のHP算出基準は維持しています。

## ソロの自動プレイ

実際の敵生成・移動・経験値回収・3択を使い、各キャラクターを120秒×2シードで確認。メイジは水から開始し、反応相手を優先選択。

| キャラクター | 平均レベル | 平均撃破数 | 合計死亡回数 |
|---|---:|---:|---:|
| アーチャー | 16.5 | 346.5 | 3 |
| メイジ | 13.5 | 360.5 | 6 |
| ウォリアー | 21.5 | 364.5 | 1 |
| ナイト | 21.5 | 361.5 | 1 |
| ランサー | 20.0 | 345.0 | 1 |

メイジは経験値の引き寄せを入れる前のLv10・8からLv15・12へ改善しましたが、2回合計6回の死亡が残りました。経験値回収を優先する自動移動の結果であり、手動操作でも同じ差が出るとは限りません。物理と属性のソロ生存力が完全に揃ったとは判断せず、今後の確認点として残します。最終物理ビルドは4種の自動ボス戦で3勝1敗でした。
