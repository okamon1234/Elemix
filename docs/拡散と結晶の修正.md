# 拡散と結晶の修正

2026-09-26。Unity 6000.0.43f1 / Photon Fusion 2。

## 変更した動作

拡散が通常反応と同じ待ち時間を使い、ボスではその後0.75秒間、蒸発や融解などを妨げていた問題を修正しました。

- 風は付着済みの炎・水・氷・雷を周囲3.5mへ広げます。元の属性も残り時間も変更しません。
- 拡散の待ち時間を通常反応から分離しました。風の直後でも蒸発・融解・凍結などを起こせます。
- 拡散は付着を広げる支援効果です。追加倍率・周囲への追加ダメージを廃止し、風武器本来のダメージは残します。
- 周囲の敵に別属性が付いている場合は上書きしません。広げる相手がいない単体ボスには、無意味な「拡散」表示を出しません。
- 風そのものは付着しません。木・土・光・闇の付着も風で消しません。
- 攻撃した本人が結晶バリアを持っている間、結晶は発動しません。土攻撃は付着属性・残り時間・通常反応の待ち時間を変更せず、結晶アイテムも生成しません。
- 敵に土が残っていた場合、バリア所持者の炎・水・氷・雷は結晶を作らず、次の反応に使える属性として付着します。
- バリアを失うと再び結晶を作れます。判定は攻撃した本人ごとなので、仲間のバリア所持は影響しません。

通常反応の待ち時間は雑魚0.4秒・ボス0.75秒のままです。拡散はこの待ち時間を発生・延長させません。

## マルチプレイ

攻撃要求と一緒に攻撃者のバリア状態を送信し、通常の状態同期が到着する前でも結晶を抑止します。通信形式を更新したため、参加者全員が今回のWindows版を使用してください。

## 手動確認

1. メイジで水を選び、風と炎を追加する。ボスに水→風→炎が当たったとき、蒸発が出ることを確認する。
2. ソロで水が付いた敵に風を当て、近くの未付着の敵にも水が付くことを確認する。別の属性が付いた敵はその属性を保持する。
3. 土と水などで結晶を作って拾う。バリア表示中は、土攻撃が当たっても新たな結晶が出ず、水などの付着が残ることを確認する。
4. 一度被弾してバリアを消費する。再び結晶が生成できることを確認する。
5. 2人で同じ部屋に入り、片方だけバリアを取得する。取得者は結晶を作れず、未取得者は作れることを確認する。

ローカルプロジェクトに追加のInspector設定はありません。

## 検証結果

- Unity PlayMode：370項目成功。拡散を連続20回受けた後の通常反応、付着時間、周囲への無ダメージ拡散、バリア中の抑止と解除後の再開を含みます。
- Photonクラウドの独立2クライアント：ホスト22項目、ゲスト26項目成功。ゲストの水→風→土で水が残ること、新たな結晶が生成されないこと、その後の木で開花・雷で超開花へ連鎖することを確認しました。
- Windowsビルド：エラー0・警告0。最終Windows版の日本語属性ガイドを描画して確認しました。
- 自動操作による機能回帰検証です。人間による長時間プレイ、4人接続、全ビルドの火力再測定は今回実施していません。
