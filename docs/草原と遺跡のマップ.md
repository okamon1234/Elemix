# 草原と遺跡のマップ

ホームの「マップ：草原／遺跡　変更」から出撃先を選択します。選択は次回起動時にも保持されます。ソロの地形だけが変わり、敵が時間経過で強くなる仕組みや育成ルールは共通です。宝箱は今回の実装に含めていません。

## 地形の違い

| マップ | 区画 | 立ち回り |
|---|---|---|
| 草原 | 開けた野原・林の縁・岩場 | 広い街道で群れを引き離す。木や岩を回り込んで追撃をかわす |
| 遺跡 | 中央広場・石柱の回廊・崩れた外壁 | 通路へ敵を誘い、広場で切り返す。柱や壁で敵弾を遮る |

各区画の中央を通る道が隣の区画へつながります。遺跡のアーチは左右の柱に衝突し、中央を通り抜けられます。草むらと小さな飾りには当たり判定がありません。

右上の周辺マップは、灰色が障害物、水色が自分、黄色が出発地点です。現在の区画名と、出発地点からの距離も表示します。

## グラフィック

草地・苔むした石畳と、木・岩・倒木・草むら・石柱・壁・アーチ・瓦礫の素材を新しく制作しました。描き込みのあるキャラクターと敵に合わせた絵柄です。味方・敵・弾・危険予告が木の葉などで隠れないよう、地形の絵はキャラクターより後ろに表示します。

素材は `Assets/RogueSurvivors/Resources/RogueSurvivors/Art/Maps/` に保存しています。[制作方法とプロンプト](マップ素材の制作記録.md)を参照してください。

## 生成と衝突

24m四方を1区画として、プレイヤーの周囲9区画だけを維持します。遠ざかった区画は解放します。同じマップの同じ座標では同じ配置になり、戻ってきても道や壁は変わりません。毎回ランダムに配置を変える方式ではありません。

生成はプレイヤー位置による障害物の間引きを使わないため、再訪時に障害物が増える問題を避けています。敵の出現候補が障害物と重なる場合は、近くの通行可能な場所へ補正します。従来のボス会場の境界・障害物配置は独立して維持しています。

## 手動確認

1. HomeSceneで「出撃マップ」を開き、草原を選んで出撃。草地、木・岩、周辺マップを確認する。
2. 上下左右へ数区画歩き、道が途切れず進めること、来た道を戻っても障害物が同じ場所にあることを確認する。
3. 遺跡へ出撃し、柱・壁でプレイヤーと敵弾が止まること、アーチの中央を通れることを確認する。
4. それぞれのマップで弓兵・突進獣が出るまでプレイし、地形を使った回避と敵の追尾を確認する。
5. ソロ終了後、保存ビルドでボス戦へ進めることを確認する。

現行ローカルプロジェクトに追加のInspector設定は不要です。画像の取り込み設定も自動で適用します。
