# 3属性連鎖とボス分岐の検証

2026-09-25。Unity 6000.0.43f1 / URP / Photon Fusion 2。

## 実装した内容

- 5職業をボスと同じ描き込みのある絵柄に更新。停止＋左右の一歩の3コマを切り替える。物理12種・属性9種・合体10種の計31武器も新しい透過画像に変更し、攻撃・強化カード・初期属性選択に反映。ホームに3タブのキャラ・武器図鑑を追加。
- メイジはホームで初期属性を9種類から選び、対応武器Lv2で開始。選択をセーブ・通信へ保持し、死亡時にも初期武器を保護。既存セーブは炎として互換読み込み。
- 木＋水の開花は敵に3秒残る種。種の付いた敵に雷を当てると超開花、炎なら烈開花。原神の段階式反応を参考に、本作の自動攻撃用に敵への付着方式とした。
- 種は敵1体につきチーム共有1個。重複起爆・上書き・時間延長を防止。超開花は単体2.2倍、烈開花は半径3.6mへ1.55倍。倍率の基準は開花を作った攻撃と起爆した攻撃の平均威力。味方への自傷なし。
- 起爆は通常の2属性反応とは別の段階として受け付ける。2属性の待ち時間中に別属性を当てても、成立待ちの付着を不用意に消さないよう修正。
- 4ボス×3形態の透過アートを新規作成。ドラゴンと守護者は画像のセルから翼・枝がはみ出さないよう配置も調整。
- 最初に壊す部位で主な攻撃が分岐し、その後に壊した部位で追加攻撃が変わる。破壊順を通信に保存。HP50%の第3形態は、全16ルートで開始攻撃が第2形態と異なる。
- 円盤鎌の不透明度を48%、他の物理飛翔武器を76%へ。敵の予告と敵弾は味方の攻撃より前面。軌跡も短縮し、当たり判定と威力は維持。
- ボス戦のカメラはプレイヤーとボスの間へ最大3.5m寄せる。上側に少し余白を設け、頭とHUDが重なる問題を軽減。

## 確認結果と範囲

- Unity PlayMode統合検証：**329項目成功**。初期属性9通りの保存・死亡取り消し、種の寿命と重複防止、3属性のダメージ、破壊順と第3形態分岐を含む。
- Photonクラウドの独立2クライアント：**ホスト18項目、ゲスト20項目成功**。ゲストからの種生成・雷での起爆・消費の同期、初期属性、破壊順、3形態、勝利を確認。
- ボス火力比較15ケース＋移動・回避を伴うボス戦20ケースをUnityの実シーンで実行。人間による手動プレイではなく自動操作。4人での長時間プレイは未実施。
- 種の状態を引き継ぐ復元処理は検証済み。実際の回線切断による権威移行を今回クラウド上で再現してはいない。
- 最後のカメラ・画像変更は描画のみで、威力や命中判定を変えていない。最終ビルド・実画面の結果は末尾に記載。

## 移動するボスとの比較で気になった点

ドラゴンは属性4構成が約71〜73秒で撃破し、物理は途中で死亡した。ゴーレム・大グモ・守護者は、今回の単純な回避操作では全5構成が途中で死亡した。各1回の結果なので勝率や人間の難易度を断定できないが、破壊順で変わる攻撃への対処はかなり要求される。

自動操作は危険範囲から離れる局所的な回避を優先するため、「縮む巣の出口へ向かう」「輪の内側へ先に入る」などの攻略を十分に実行できない。この結果だけを理由にボスを一律弱体化してはいない。人間の次回プレイでは、予告を見て避ける時間が足りるかを優先して確認したい。

## 次に入れると面白くなりそうな機能

1. **部位へピンを置く作戦共有**：チームで「頭から壊して雷型にする」などの選択を合わせる。今回の破壊順分岐をマルチ固有の遊びにできる。
2. **反応の役割表示**：「種を作れる味方」「雷で起爆できる味方」をロビーとHUDに表示。味方同士で反応をつなぐ意味が見え、将来の集中同期による行動遅延とも相性がよい。
3. **部位破壊の短い攻撃チャンス**：追加の部位破壊後に1秒前後のよろめきを与える案。難しさを保ちながら、正しい部位を狙った成果を攻撃機会として返せる。今回未実装。
4. **合体先の予約**：剣・盾・槍など、複数レシピが成立する場合に目指す進化を指定する。意図しない自動合体を減らし、ビルド構築に選択を加える。

## Unityで手動設定が残る箇所

このローカルプロジェクトでは、新しいスクリプト・画像のインポート・日本語UI・同期を実ファイルへ反映済み。追加のInspector操作は不要。新しいPCでGitHubから取得する場合は、従来どおりFusion SDKと自分のApp IDの設定が必要。旧v5と新v6はネットワーク版番号を分けたため同室には入らない。全員が新しいビルドを使う。

## 手動プレイの確認手順

0. ホームの「キャラ・武器図鑑」で5職業と3タブの全31武器を確認。各職業で出撃し、停止・移動・左右反転・被弾色が切り替わることを確認。
1. HomeSceneでメイジを選び、初期属性を水などに変更して出撃。HUDの武器が選択したLv2で始まることを確認。
2. 水＋木＋雷を取得し、硬い敵やボスの上に出る種と追尾弾を確認。雷を炎に替えると広い爆発へ派生する。種は敵への攻撃で起爆する。
3. ボス練習を2回行い、最初に壊す部位を変える。HP下のルート表示と、第2形態の主な攻撃を比較。
4. 全装甲破壊後、HP50%の第3形態で画像と開始攻撃が変わることを確認。
5. 円盤鎌を育て、敵の予告線が刃より前に見えること、敵弾を追えることを確認。
6. 同じ新ビルドの2人で同じ部屋に参加し、別々の人が水・木・雷を担当して連鎖と部位破壊を確認。
