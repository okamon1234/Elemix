# 部位ピンと破壊チャンス

2026-09-26。ソロのボス練習とPhoton Fusion 2のマルチボス戦に追加。

## 操作

- 画面左の部位ボタンをクリック：その部位を仲間に共有。
- Q／ゲームパッドRB：生きている部位を順に指定。
- ボスの部位の近くをマウス中クリック：その方向の部位を指定。
- E／ゲームパッドLB：自分のピンを解除。

1人1個、8秒表示。更新は最短0.4秒間隔。P番号と色で誰のピンかを示す。部位破壊・死亡・期限切れでマークを非表示にする。指定した部位を最初に壊した場合の攻撃傾向も表示する。

ピンは仲間へ方針を伝えるもの。プレイヤーを自動移動させたり、反対側の装甲を貫通させたりしない。指定した方向へ回り込んで攻撃する。

## 部位破壊の報酬

1. 破壊直後、ボスは1.1秒ひるみ、移動と新たな攻撃を止める。この間はボス本体への接触ダメージもない。既に出た弾・床攻撃は残る。
2. その後4秒間、破壊した側のボス中心から3.6m以内が弱点になる。金色の扇形の輪郭と残り秒数で表示する。
3. 弱点側へ近づくと、他の装甲が残っていても本体に攻撃できる。物理は1.6倍、属性は1.3倍。反応の追撃は1.15倍。
4. 形態変化の2.4秒間は無敵を維持し、チャンスの残り時間を消費しない。

破壊1回につき本体最大HPの3.5%を予算にする。装甲が残る間は弱点によって通るダメージ全体、全装甲破壊後は通常ダメージに加えたボーナス分だけがこの予算を消費する。予算が尽きると弱点ボーナスは終了し、全破壊後の通常攻撃はそのまま有効。短時間に複数部位が壊れた場合は最後の部位へ切り替え、時間と予算を加算しない。

既存の「破壊ごとに攻撃力+7.5%・頻度+8%」「最初の部位破壊で第2形態」「HP50%で第3形態」は維持する。

## マルチプレイ

各プレイヤーの権威オブジェクトが自分のピンと有効期限を同期する。ボスの権威側だけが弱点ダメージと予算を計算し、破壊部位・残り時間・ひるみ・予算を全員に同期する。状態復元にも同じデータを使用する。

ネットワーク版番号を `Elemix-Fusion2-v8-part-tactics` に更新した。旧ビルドとは同室にならないため、参加者全員が新しいWindows版を使用する。

## Unityでの手動設定

現在のプロジェクトでは追加のInspector操作は不要。HUD・部位破壊処理・プレイヤーに実行時に必要なクラスを追加する。Fusionの同期項目は既存のネットワーククラス内へ追加した。

## 手動確認

1. ホームからボス練習に入り、Qと部位ボタンでピンを切り替える。表示された側から攻撃する。
2. 2人で同じ部屋へ入り、別々の部位へピンを置く。相手の番号付きピンも見え、Eで自分のピンだけ消えることを確認。
3. 部位を壊し、ひるみ後に金色の範囲へ近づく。残りの装甲があっても本体HPが減ることを確認。
4. 遠くや反対側からでは弱点ボーナスを受けないこと、変身中は4秒のチャンスが保たれることを確認。
5. 画面に残る敵弾や予告を避けながら攻める。4秒経過または上限到達後は通常の装甲ルールに戻る。

自動検証結果は同日の[検証記録](部位戦術の検証結果.md)に記載する。
