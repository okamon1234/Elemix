# キャラクターと武器の見た目

2026-09-25。既存の4ボス3形態に合わせ、描き込みのある金属・革・布の質感へ統一した。

- 5職業：アーチャー、ウォリアー、ナイト、メイジ、ランサー。停止・左足・右足の3コマで歩行する。職業色と装備の輪郭で識別できるようにした。
- 物理12種：短剣、斧、ハンマー、剣、盾、ナックル、鎌、槍、鞭、ボウガン、ブーメラン、回転剣。
- 合体10種：大剣、回転大斧、投刃グローブ、ハルバード、投擲戦斧、鎖鉄球、スパイクシールド、円盤鎌、鎖鎌、連射ボウガン。
- 属性9種：炎の玉、水のオーブ、氷の槍、雷の指輪、風の弓、木の種、土のハンマー、光の槍、闇のオーブ。属性色を残し、杖一辺倒の形を避けた。

ホームに「キャラ・武器図鑑」を追加。強化カードとメイジの初期属性選択にも新画像を表示する。戦闘中は投擲・なぎ払い・回転する武器を置き換え、属性攻撃には発動時の武器の姿を添えた。命中判定、威力、間隔は変更しない。

円盤鎌は中央が開いた輪郭と48%の不透明度で視界を確保。敵の予告線と敵弾を味方の武器より前面に表示する。

## 画像の保存先と作り方

生成方法：内蔵の image_gen（built-in）。外部CLIは使用していない。既存ゲームの画像を転載せず、本作用の画像を生成した。

保存先：`Assets/RogueSurvivors/Resources/RogueSurvivors/Art/Polished/`。

- `{ranger,warden,knight,mage,lancer}_v7.png`：横3コマ。
- `PhysicalWeapons_v7.png`：4列×3行。
- `ElementWeapons_v7.png`：3列×3行。
- `FusedWeapons_v7.png`：5列×2行。

[使用したプロンプト](キャラクターと武器画像生成プロンプト.json)。透明PNGをそのまま保存し、Unity内でセルを切り出す。インポート設定は専用クラスが自動設定する。

## 確認するところ

ホームで図鑑の3タブを切り替え、全武器の画像と名前を確認。各職業で出撃し、歩行・停止・左右反転・被弾点滅を確認する。合体武器を育てても敵の赤い予告が隠れないこと、メイジの属性選択や強化カードの説明が読めることを確認する。

自動検証の範囲とボス戦バランスの制限は[検証報告](3属性連鎖とボス分岐の検証.md)を参照。
