# スクリプトの役割一覧

自作C#スクリプト 141 ファイル。Photon SDKやUnityパッケージの内部コードは対象外です。

## 処理の流れ

ホーム → SoloSceneで育成 → JSON保存 → ロビー → FusionでMultiBossSceneへ移動 → ビルドから難度を決定 → 部位破壊で第2形態 → HP50%で第3形態 → 勝利。

命中は武器 → EnemyHealth → ElementReaction → BossParts／本体の順です。オンラインのボスHP・部位・属性は権威側が更新します。各プレイヤーの被弾は自分の端末で判定する協力プレイ用の設計です。競技向けの不正対策サーバーではありません。
