# プレイ検証で見つけた改善案

2026-09-25。実際のUnityシーンを自動操作した測定、攻撃の描画、ゲームの処理から確認しました。人間が操作した楽しさの評価や4人の長時間プレイを終えたものではありません。数値は[物理合体とバランス検証](物理合体とバランス検証.md)を参照してください。

## 今回直した点

- **合体したのに新しい武器になった感じが薄い。** 素材2本の攻撃を停止し、1本の専用攻撃に置換。空いた枠へ別の武器を入れる遊びに変更しました。
- **遠距離の風の弓が、大型ボスで意図以上に強い。** 散開する矢が同じボスへ集中する追加分を抑え、通常の群れ処理は維持しました。
- **物理の回転・鉄球が本体に当たりにくい。** 軌道と命中頻度を確認し、威力を調整。見えている飛翔武器の線分で命中を判定します。
- **槍での育成が不安定。** 最初の2分比較で、ランサーが5回死亡しLv8で終わる条件がありました。通常敵への突き幅を0.7から0.9、基準の発動間隔を1.1秒から1秒に調整し、死亡時の装備構成も記録して再検証しました。選んだ合体と距離による差が大きく、弱点が完全に解消したとは判断していません。
- **ハルバード合体直後の単体火力が落ちる。** 素材を消費する方式に変えた後も威力設定が低く、2段とも当たる場合の火力が素材2本の合計を下回っていました。合体後の威力を引き上げ、ランサーを再測定しました。
- **属性が名前から伝わりにくい。** 全9属性の名前を武器名の先頭に統一しました。

## 優先して改善したい点

### 1. 合体先を自分で決める楽しさ

現在は条件を満たすと自動合体します。剣・盾・槍などが同時に揃った場合、レシピの登録順で結果が決まります。カードには合体候補を表示していますが、意図しない合体で別の素材を使ってしまう可能性があります。

次は「合体が完成する強化カードに、完成する武器と消費素材を大きく表示」「複数候補があるときだけ合体先を選択」がよいと思います。さらにホームで狙うレシピを1つ指定し、必要な素材に印を付けると、抽選を見ながら自分でビルドを組む楽しさが増します。確定入手にはせず、現在の抽選優遇は残す案です。

### 2. 死亡後に立て直せるか

敵は時間で強くなり続ける一方、死亡すると直近3強化を失います。初回比較ではアーチャーが同じ2分でLv21に到達する条件で、ランサーはLv8でした。職業差だけでなく、死亡後の火力低下が次の死亡を招く構造を疑う必要があります。

指定された「3強化を失う」は残したまま、復活位置の安全性や、復活直後に敵の包囲から抜ける支援を改善するのが候補です。死んだ方が経験値や火力で得をする救済にはしません。まず死亡前後30秒の再死亡率を測り、必要量を決めるべきです。

### 3. どの部位を先に壊すかを攻略にする

現在は右・上・左・下の装甲を全て壊し、壊すほど全体の怒りが上がります。回り込む判断はありますが、壊す順番の効果は共通です。

例えば、ドラゴンの翼を先に壊すと突進が減る代わりに地上ブレスが激しくなる、尾を先に壊すと後方が安全になる代わりに正面が強化される、といった交換条件が考えられます。単なる弱体化ではなく、「今のパーティが避けやすい攻撃に変える」設計です。人数だけではなく、持ち寄った装備と役割で攻略が変わるため、本作の差別化に向いています。

## 装備・機能・新要素の候補

| 優先 | 候補 | 狙い・制約 |
|---|---|---|
| 高 | ロビーの仲間ビルド一覧・狙う部位のピン | 誰が元素を付け、誰が超電導後に殴り、どの部位を狙うかを相談できる。まずは情報表示から。 |
| 高 | 反応の原因表示 | 「水→雷：感電」の短い表示と、自分／味方の付着アイコン。ダメージの数字だけでなく、組み合わせが働いた理由を伝える。画面全体への文字連発は避ける。 |
| 中 | 往復する物理武器の帰路を見せる | 現在も復路は移動したプレイヤーへ戻る。帰り道を敵に重ねる位置取りを分かりやすくし、属性の付着連携とは別の上達要素にする。 |
| 中 | 合体の枝分かれ強化を1回だけ選ぶ | 例：投刃グローブの「扇状で群れ処理」／「狭く集中してボス向け」。火力の一律増加ではなく得意な場面を選ばせる。 |
| 中 | 回復系の装備選択 | 「無傷で回復を早める」／「味方の近くで応急手当を少し共有」など。既存の回復条件・使用回数を基準にし、攻撃を無視して耐える構成にしない。 |
| 後 | 協力による短いボス攻撃中断 | 別方向の部位へ一定時間内に異なる役割の攻撃を当てると、危険行動の予告を少し延ばす。再発動待ち時間を付け、連続で封じ込めない。 |

武器数をすぐ増やすより、まずは**合体の選択、反応の原因表示、部位破壊の順番**を深くしたいです。現在の12物理・9属性・10合体でも組み合わせは十分増えました。選んだ理由と、味方との組み合わせの効果が伝わることの方が、次の改善として効果が大きいと考えます。

## 追加で計測したい点

- ボス本体への物理DPSは、中盤以降に属性より低い傾向が残っています。装甲補正・シールド込みの生存率と、回避中にも当たる範囲攻撃を含めて判断します。
- スパイクシールドはコード上、同じ敵に一度しか当たらず、ボス単体では跳弾先がありません。群れ向けという性格はありますが、ボス戦での用途をもう一つ用意したいです。部位を跳弾の対象にする、戻りの一撃を設ける、ボスが小型の敵を呼ぶ攻撃を持つ、といった候補があります。今回のボス比較は代表構成であり、この合体単独の優劣までは実測していません。
- 合体5本は育成投資が大きいため、通常の準備時間で何本まで完成するかを調べたいです。「完成してから遊ぶ時間がほとんどない」状態なら、必要レベルよりもまず選択肢と準備時間の案内を見直します。
- ボスHPには推定DPSによる補正があります。装備を強くしてもボスHPが増えるので、育成の成果を感じにくい可能性があります。参加者のレベル合計を主軸にし、装備補正の上限・伸び方を比較する余地があります。
- 4人分の攻撃演出で予告が隠れないか、味方の演出濃度設定が必要かは、4人実戦で確認が必要です。

将来の脳波連携は、上の「協力による短い中断」の入力として接続するとゲームの中心に結び付きます。通常の協力行動でも成立する仕組みを先に作り、集中同期は別の発動条件として比較できる形にすると、研究とゲーム双方で評価しやすいと思います。ここに記載した候補は、今回の実装済み機能と区別しています。
